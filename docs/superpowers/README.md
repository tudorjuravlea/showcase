# Build history

"MockupAnimate" in these documents is the project's original working name.
The public project is Showcase. The docs are kept verbatim as history.

These plans and specs are the historical build process of this project,
written with the [Superpowers](https://github.com/obra/superpowers)
subagent-driven development workflow. They document how the project was
designed and built, phase by phase, and they stay in the repo because
source-code comments reference their section numbers as design rationale.

They are not user documentation. For that, see the top-level README and
[docs/LESSONS.md](../LESSONS.md).
